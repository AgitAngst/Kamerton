## Why

Этап 0.5 по SPEC.md — профили. У EarTrumpet громкость программ сбрасывается на 100 % (#1249, #1495) и
устройство программы не запоминается (#521); просят громкость по умолчанию для новых программ. Профили
«Игра / Работа / Наушники» и включение профиля при подключении устройства закрывают то, что EarTrumpet
делал аддоном Actions.

## What Changes

- Память громкости: громкость и «без звука» каждой программы (по exe) запоминаются; программа появилась
  снова — громкость возвращается. Выключатель «Запоминать громкость программ» (включено по умолчанию).
- Громкость новых программ: для программы, которой ещё нет в памяти, — заданная (выключено по умолчанию).
- Профили: имя, устройство вывода и записи по умолчанию, громкость, «без звука» и устройство каждой
  программы. «Сохранить текущее» — снять с того, что есть сейчас; «Применить» — вернуть: запущенным
  программам сразу, остальным — когда появятся (через память).
- Правило профиля: «Включать при подключении» выбранного устройства.
- Страница «Профили» в окне (кнопка внизу) и подменю «Профили» в меню значка.
- Хранение — `settings.txt`. Версия 0.5.0.
