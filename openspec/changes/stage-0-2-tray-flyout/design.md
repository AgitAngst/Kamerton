## Context

Зачем — proposal.md. Ядро звука — `src/audio` (`Audio`, события, команды, уровни по запросу). Окна в
программе ещё нет. Новых крейтов, кроме `anvil-ui` и `eframe`, брать нельзя без слова владельца, поэтому
трей, меню и колесо делаются через `windows`.

## Goals / Non-Goals

**Goals:** в покое — ноль работы (окно спрятано, уровни не читаются, перерисовок нет); окно появляется
мгновенно и всегда целиком на экране.

**Non-Goals:** смена устройства по умолчанию и перевод программ (0.3), микрофоны в окне (0.3),
горячие клавиши (0.4), настройки и полное окно микшера (0.6), логарифмическая шкала (0.6).

## Decisions

1. **Трей — свой поток с невидимым окном сообщений** (`Shell_NotifyIconW`, `TrackPopupMenu`).
   Наружу — события в канал + `request_repaint`. *Иначе:* крейт `tray-icon` — новая зависимость.
2. **Окно — один viewport eframe без рамки, поверх всех, без кнопки на панели задач.** Показ и прятание
   делает Win32 (`SetWindowPos`/`ShowWindow` по HWND окна): спрятанное окно eframe не рисует и само не
   проснётся. Место считает чистая функция `placement::place` (прямоугольник значка, рабочая область
   монитора, край панели задач, размер окна → левый верхний угол); её покрывают тесты.
3. **Фокус.** Окно получает фокус только по щелчку пользователя по значку (`SetForegroundWindow` разрешён,
   потому что щелчок был у нас). Потеря фокуса — окно прячется. Само окно никогда не всплывает без щелчка.
4. **Значок в трее** — глиф шрифта Windows «Segoe Fluent Icons» (Win11) / «Segoe MDL2 Assets» (Win10),
   нарисованный GDI в 32-битную картинку: тот же вид, что у системного значка звука, светлый или тёмный
   по теме панели задач. Четыре уровня (без звука, 0, ≤33, ≤66, >66 %). *Иначе:* знак набора — цветной
   квадрат, в трее рядом с системными значками выглядит чужим. Внутри окна шрифтовых значков нет
   (правило набора): значок динамика рисуется линиями в сетке 24 × 24 (`src/icons.rs`).
5. **Колесо над значком** — низкоуровневый хук мыши в потоке трея: только сравнивает курсор с
   прямоугольником значка и шлёт шаг в канал; событие колеса над значком поглощается. Сам хук ничего
   долгого не делает.
6. **Значки программ** — `SHGetFileInfoW` по пути exe → пиксели (`GetIconInfo` + `GetDIBits`) →
   текстура egui; кеш по пути. Нет пути — значок `Window` набора.
7. **Уровни** — только пока окно видно: `audio.peaks()` раз в кадр, кадры раз в 33 мс. Спрятано — кадров нет.
8. **Язык и тема** — системные (`anvil_ui::lang::system_language`, `ThemeChoice::System`); для проверки
   снимков — переменные `KAMERTON_LANG=ru|en`, `KAMERTON_THEME=light|dark`.
9. **Один экземпляр** — именованный мьютекс `Local\Kamerton`; второй запуск без ключей выходит.
   Консольные ключи работают и при запущенном трее. Release-сборка — подсистема `windows`; для ключей
   консоль родителя подключается `AttachConsole`.

## Risks / Trade-offs

- [Хук мыши тормозит всю систему, если поток трея завис] → в хуке только сравнение прямоугольников;
  поток трея ничего не ждёт от звука.
- [Прозрачное окно OpenGL на Windows ненадёжно] → окно непрозрачное, углы — регион окна
  (`CreateRoundRectRgn`), тень — нет.
- [В Win10 нет «Segoe Fluent Icons»] → запасной «Segoe MDL2 Assets», глифы с теми же кодами.
