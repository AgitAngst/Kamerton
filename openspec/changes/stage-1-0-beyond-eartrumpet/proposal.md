## Why

Паритет с EarTrumpet закрыт (этапы 0.2–0.9). Владелец 24.10.2026 согласовал порядок работ «сверх EarTrumpet»:
сначала плашка громкости (OSD), высокий контраст и стиль Win11, поиск по настройкам, усиление выше 100 % и
командная строка; потом ограничитель, автоприглушение и правила по программам (следующий этап); эквалайзер и
маршрутизацию через свой драйвер не берём. Команда: «Начинай».

## What Changes

- **Командная строка.** `kamerton --set <цель> <громкость>`, `--mute <цель> [on|off|toggle]`, `--get <цель>`:
  отдельный процесс на время команды, со своим ядром звука; трей и окно узнают об изменении от Windows.
  Для скриптов, Stream Deck, планировщика.
- **Плашка громкости (OSD).** Громкость устройства по умолчанию изменили колесом над значком или сочетанием
  клавиш (и «без звука») — у панели задач на 1,5 с появляется маленькая плашка: значок, ползунок, число.
  Выключатель в «Настройках → Окно». Окно микшера открыто — плашки нет, оно само показывает громкость.
- **Высокий контраст и стиль Win11.** При включённом в Windows высоком контрасте окно рисуется цветами
  системы (фон окна, текст, выделение, серый текст).
- **Поиск по настройкам.** Поле на странице «Настройки»: набираешь — остаются подходящие строки и разделы,
  пустой результат — «Ничего не найдено».
- **Усиление выше 100 % — вынесено из этапа.** См. design.md (решение 5): штатный Core Audio выше 0 дБ громкость
  не поднимает; нужна своя обработка звука (захват + повторный вывод) — это уровень «своего драйвера», который
  владелец не берёт. Нужно решение владельца, пока не делаем.
- Версия 1.0.0 (по схеме: после 0.9.x — 1.0.0; подъём по команде владельца 24.10.2026). Тег и выпуск — по команде.

## Capabilities

### New Capabilities

- `command-line`: управление громкостью и «без звука» из командной строки.
- `volume-osd`: плашка громкости.
- `high-contrast`: вид при высоком контрасте Windows.
- `settings-search`: поиск по странице «Настройки».
