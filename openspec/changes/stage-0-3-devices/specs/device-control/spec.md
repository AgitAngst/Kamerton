## Purpose

Знать и менять устройство по умолчанию и устройство связи для вывода и записи — так же, как это делает
панель «Звук» Windows.

## ADDED Requirements

### Requirement: Роли устройства в снимке
Система SHALL отмечать у каждого устройства, является ли оно устройством по умолчанию (роль console) и
устройством связи (роль communications) для своего направления, и сообщать о смене любой из ролей не
позже чем через 200 мс.

#### Scenario: Разные устройства для связи и по умолчанию
- **WHEN** колонки — по умолчанию, гарнитура — для связи
- **THEN** у колонок отмечено «по умолчанию», у гарнитуры — «для связи»

### Requirement: Смена устройства по умолчанию
Команда «сделать по умолчанию» SHALL назначать устройство по умолчанию сразу для ролей console, multimedia
и communications; команда «сделать для связи» — только для communications. Устройства уже нет или API
недоступен — SHALL вернуться ошибка, программа продолжает работу.

#### Scenario: Наушники по умолчанию
- **WHEN** выбирают «сделать по умолчанию» у наушников
- **THEN** наушники — по умолчанию и для связи, приходит событие изменения устройств
