## Purpose

Окно, страницы и плашка остаются читаемыми при включённом в Windows высоком контрасте.

## ADDED Requirements

### Requirement: Цвета системы
Когда в Windows включён высокий контраст, программа SHALL рисовать окно, страницы и плашку цветами системы
(фон окна, текст, серый текст, выделение, текст выделения), а не палитрой набора. Выбор MUST сниматься сразу,
когда высокий контраст выключен, без перезапуска. Свои hex-цвета в интерфейсе MUST не использоваться.

#### Scenario: Включили высокий контраст
- **WHEN** пользователь включает тему высокого контраста
- **THEN** при следующем показе окно и плашка рисуются цветами системы, строка устройства по умолчанию и фокус
  различимы без цвета акцента
