## Context

Зачем — proposal.md. Ядро звука (`src/audio`) знает устройства и программы; окно и трей — 0.2. Открытых API
нет: устройство по умолчанию Windows меняет через `IPolicyConfig` (COM, `CLSID 870AF99C-…`), а перенос
программы — через WinRT-фабрику `Windows.Media.Internal.AudioPolicyConfig` (так делают «Параметры →
Громкость приложений» и EarTrumpet).

## Goals / Non-Goals

**Goals:** все действия — команды ядра звука (поток `audio`), окно и трей только просят; сбой API не
роняет программу.

**Non-Goals:** горячие клавиши (0.4), память громкости и маршрутов (0.5), полное окно микшера (0.6).

## Decisions

1. **`policy.rs` — единственное место недокументированного.** `IPolicyConfig::SetDefaultEndpoint` для ролей
   console + multimedia + communications («по умолчанию») или только communications («для связи»).
   `AudioPolicyConfig`: фабрика через `RoGetActivationFactory`, IID зависит от сборки Windows — пробуем
   `ab3d4648-…` (новые), затем `2a59116d-…` (старые). Методы `SetPersistedDefaultAudioEndpoint`,
   `GetPersistedDefaultAudioEndpoint` — 20-й и 21-й после IInspectable. Id устройства в этом API —
   `\\?\SWD#MMDEVAPI#<id>#{e6327cad-…}` (вывод) или `…#{2eef81be-…}` (запись); упаковка и распаковка —
   чистые функции с тестами. Фабрика не получилась — перенос недоступен (флаг в снимке), остальное работает.
2. **Перенос программы** — всем её pid, для ролей console и multimedia, по направлению устройства.
   «Как в системе» — пустая строка (сброс). Windows сама переводит сессии; ядро увидит их по событиям.
3. **Закреплённое устройство** читается для каждого нового процесса один раз (кеш по pid) и после
   переноса — не на каждом перечитывании.
4. **Перетаскивание** — egui `dnd`: источник — строка программы, цель — блок устройства того же
   направления; во время перетаскивания цели подсвечиваются.
5. **Настройки** — `%APPDATA%\Kamerton\settings.txt`, строки `ключ=значение`, неизвестные ключи
   сохраняются как есть. Без новых зависимостей.

## Risks / Trade-offs

- [IID и порядок методов `AudioPolicyConfig` меняются от сборки к сборке] → две известные раскладки;
  неизвестная сборка — перенос недоступен с пояснением, а не падение.
- [Перенос не применяется к уже играющему звуку у некоторых программ] → это поведение Windows; в
  подсказке: «может потребоваться перезапуск воспроизведения».
- [Проверить смену устройства и перенос можно только на настройках пользователя] → в долгах владельца.
