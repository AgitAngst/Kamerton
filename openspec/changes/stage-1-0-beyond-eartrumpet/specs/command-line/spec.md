## Purpose

Управление громкостью и «без звука» программы, устройства по умолчанию или любого устройства из командной
строки — для скриптов, Stream Deck и планировщика.

## ADDED Requirements

### Requirement: Задать громкость
Команда `kamerton --set <цель> <громкость>` SHALL задать громкость цели. Громкость MUST быть процентами:
`45`, `45%` (абсолютная, 0–100) или `+5`, `-5` (от текущей, результат обрезается до 0–100). Команда MUST
выполняться отдельным процессом и не требовать запущенного трея.

#### Scenario: Абсолютная громкость программы
- **WHEN** выполнена `kamerton --set chrome 30`
- **THEN** громкость всех сессий программы Chrome на всех устройствах вывода — 30 %, код выхода 0

#### Scenario: Относительная громкость
- **WHEN** выполнена `kamerton --set default -10` при громкости устройства 45 %
- **THEN** громкость устройства вывода по умолчанию — 35 %

### Requirement: «Без звука» и чтение
Команда `kamerton --mute <цель> [on|off|toggle]` SHALL включить, выключить или переключить «без звука»
(без третьего слова — `toggle`). Команда `kamerton --get <цель>` SHALL напечатать громкость и «без звука» цели
и ничего не менять.

#### Scenario: Переключить
- **WHEN** выполнена `kamerton --mute default`
- **THEN** «без звука» устройства по умолчанию меняется на противоположное

### Requirement: Цель
Цель SHALL быть словом `default` (устройство вывода по умолчанию), `input` (устройство ввода по умолчанию),
именем программы (как в окне или имя exe без `.exe`) либо именем устройства; регистр не важен, точное
совпадение важнее части имени. Если подходят несколько разных программ или устройств, команда MUST ничего не
менять и напечатать список подходящих. Цели нет — MUST ничего не менять.

#### Scenario: Неоднозначная цель
- **WHEN** выполнена `kamerton --set c 50`, а подходят Chrome и Calculator
- **THEN** громкость не меняется, в stderr — список, код выхода 3

#### Scenario: Цели нет
- **WHEN** выполнена `kamerton --set nosuch 50`
- **THEN** в stderr — `not found`, код выхода 3

### Requirement: Коды выхода
Команда MUST выходить с кодом 0 при успехе, 1 — при ошибке звука Windows, 2 — при неверных ключах или
громкости, 3 — если цель не найдена или неоднозначна. Весь вывод MUST быть по-английски.
