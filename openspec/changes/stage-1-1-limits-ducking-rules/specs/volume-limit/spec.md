## Purpose

Громкость не поднимается выше заданного потолка, кто бы её ни поднял.

## ADDED Requirements

### Requirement: Потолок
Страница «Правила» SHALL давать задать общий потолок для устройства вывода по умолчанию и свой потолок для любой
программы (проценты, 1–99; ключи `limit_device`, `limit_app.<exe>`). Когда громкость устройства по умолчанию или
программы оказывается выше потолка, Kamerton MUST вернуть её на потолок. Громкость ниже потолка MUST не меняться.

#### Scenario: Программа подняла громкость
- **WHEN** у программы потолок 60 %, а она (или пользователь) ставит 90 %
- **THEN** громкость программы возвращается на 60 %

#### Scenario: Потолок убрали
- **WHEN** потолок выключен на странице «Правила»
- **THEN** ключ удаляется из `settings.txt`, громкость больше не ограничивается
