# Design

## Решения

1. **Окно времени.** `rules::in_window(from, to, now)` — минуты от полуночи, `[from, to)`; `from < to` — в один день;
   `from > to` — через полночь (23:00–07:00); `from == to` — пустое окно (никогда). Конец — не входит.
2. **Итоговый потолок.** `rules::device_cap(день, ночь, сейчас)`: нет ни того, ни другого — `None`; в окне ночи —
   меньший из дневного и ночного; вне окна — дневной. Ночной потолок только понижает.
3. **Время — местное** (`GetLocalTime`, `sys::local_minutes`), без часовых поясов и перехода на летнее время: Windows
   сама отдаёт местное время. Нужна функция сборки `Win32_System_SystemInformation` у уже подключённого крейта `windows` —
   новой зависимости нет.
4. **Проверка.** Потолок уже считается по снимку после каждого пересмотра ядра (`tray::react_to_changes`); чтобы граница
   окна времени заметилась в тишине, минутный таймер трея (он уже есть — проверка обновлений) шлёт и `refresh`.
5. **Настройки.** `night=1`, `night_from=HH:MM`, `night_to=HH:MM`, `night_limit=NN` (1..99, по умолчанию 40); по
   умолчанию 23:00–07:00. Неразборчивое время — значение по умолчанию. Часы на странице — списки с шагом 30 минут; если в
   файле другое число минут, список показывает его как есть.
6. **Окно микшера поверх всех.** `mixer_on_top=1`; `shell::Config::always_on_top` при создании окна `--mixer`.
