# Знак Kamerton

Камертон-микшер: зубцы камертона — два ползунка уровня. Ниже ручки зубец залит, выше — бледная дорожка,
как у ползунка в окне программы; левая ручка выше правой. Выбран владельцем 24.10.2026.

| Файл | Что это |
|---|---|
| `kamerton.svg` | полный знак, viewBox 1024; источник для 64 px и крупнее |
| `kamerton-small.svg` | мелкий для 16–48 px: дорожки шире и ярче, ручки крупнее, без колец |
| `kamerton-{16,24,32,48}.png` | из `kamerton-small.svg` |
| `kamerton-{64,128,256,512}.png` | из `kamerton.svg` |
| `kamerton.ico` | кадры PNG 16, 24, 32, 48, 64, 128, 256 — значок exe (`build.rs`) |
| `kamerton-{16,32,64}.rgba` | сырые RGBA тех же размеров: SVG в 8 раз крупнее, усреднённый, — образцы для тестов растеризатора `src/mark_render.rs` |

В программе знак рисует растеризатор кадра (трей, «О программе», окно микшера): там ручки двигаются, а цвет
плитки в трее можно сменить на лазурь `#0792B3 → #03647B`. Файлы здесь — эталон вида и значок exe.

**Цвета.** Плитка — вертикальный градиент `#C24FAE → #931A82` (пурпур, акцент программы), знак `#FFFFFF`,
бледная дорожка — белый 65 % (в мелком — 70 %). Кольца вокруг ручек — цвет плитки под ними (градиент `ring`
сдвинут на величину центровки).

**Размеры (полный).** Зубец 104, бледная дорожка 56, щель 136, ручка — круг r 96 с кольцом 32, ножка 80;
мелкий: зубец 112, дорожка 80, ручка r 104.

**Центровка.** Сдвиг `(+2, −21)` у полного и `(+1, −14)` у мелкого — середина между центром габарита и формулой
`Anvil/docs/ICONS.md`. Ножка остаётся на оси, знак поднят из-за тяжёлого низа и бледного верха.

**Пересборка.** `scripts/render-icon.ps1` (нужен `resvg`: `scoop install resvg`); повторный запуск без правок
SVG даёт те же байты.
