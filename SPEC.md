# Kamerton — замысел и этапы

Микшер громкости в трее для Windows 10/11 — аналог EarTrumpet. Запрос владельца 22.10.2026:
«хороший аналог EarTrumpet»; имя Kamerton выбрано владельцем в тот же день.

## Чем EarTrumpet хорош и где слаб (на 22.10.2026)

- Умеет: громкость программ в выпадающем окне у трея, индикаторы уровня, перевод программы на другое
  устройство, устройство по умолчанию, горячие клавиши, колесо над значком, логарифмическая шкала,
  темы, 20+ языков. C#/WPF, версия 2.3.0.0, единственный сопровождающий без времени (issue #1838).
- Главные жалобы: утечки памяти и ЦП (#1424, #1722, #1740); окно не там и не того размера (#1304, #1704);
  крадёт фокус, мешает играм на весь экран (#453, #1588); программы пропадают из списка, сбрасывается
  громкость (#1845, #1249); после смены устройства программы не переходят (#1113).
- Просят и нет: горячие клавиши на отдельную программу, переключение устройств с клавиатуры (обсуждение #648).

## Цели

- Лёгкость: в покое < 30 МБ памяти и ≈ 0 % ЦП, без утечек за недели работы.
- Окно всегда на месте: любые мониторы, масштабы, положение панели задач; своё место по желанию.
- Не крадёт фокус, не мешает играм.
- Ничего не теряет: программы, устройства и громкость отслеживаются по событиям Windows.

## Этапы (согласованы с владельцем 22.10.2026; порядок можно менять)

| Версия | Этап | Что |
|---|---|---|
| 0.1.0 | Ядро звука | устройства, сессии программ, громкость, «без звука», уровни; события вместо опроса |
| 0.2.0 | Трей и выпадающее окно | значок, окно у панели задач с ползунками и индикаторами, колесо над значком, верное место, без кражи фокуса |
| 0.3.0 | Устройства | устройство по умолчанию, перевод программы на другое устройство (отдельный модуль недокументированных API), микрофоны и «прослушивать» |
| 0.4.0 | Горячие клавиши | общие, на отдельную программу, переключение устройств |
| 0.5.0 | Профили | память громкости и устройства каждой программы, наборы «Игра / Работа / Наушники», правила по подключению устройства |
| 0.6.0 | Микшер и настройки | полное окно микшера, настройки, RU/EN, темы, автозапуск |
| 0.7.0 | Надёжность | долгий прогон на утечки, смена пользователя и перезапуск службы звука, совместимость (FxSound, VR, игры) |
| 1.0.0 | Выпуск | установщик или переносная сборка, подпись, обновления |

## Риски

- Перевод программы на другое устройство — только через недокументированные API; обновление Windows
  может их сломать.
- Выпадающее окно на egui: прозрачность, анимация, место на Win10 и Win11 — проверить на первом этапе
  окна (прозрачность окна OpenGL на Windows бывает ненадёжна).
