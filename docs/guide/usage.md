# Как пользоваться

## В трее: `kamerton`

Запуск без ключей ставит значок в трей; окон на экране нет. Второй запуск без ключей ничего не делает
и сразу выходит — значок остаётся один. Окно микшера готово с самого старта, только спрятано: по щелчку
оно появляется за кадр (~10 мс). В покое Kamerton занимает ~20–28 МБ своей памяти и не тратит процессор.

**Значок** — динамик, как у системного значка звука, и показывает громкость устройства вывода по
умолчанию: без звука (перечёркнут), 0 %, до 33 %, до 66 %, выше 66 %. Цвет — по теме панели задач
(белый на тёмной, чёрный на светлой). Подсказка: `Kamerton: <устройство> — <громкость> %`.

- **Щелчок** — открыть или закрыть окно микшера.
- **Колесо над значком** — громкость устройства по умолчанию: 2 % за щелчок колеса, вверх — громче.
- **Правая кнопка** — меню: «Микшер громкости Windows» (`sndvol.exe`), «Параметры звука»
  (`ms-settings:sound`), «Выход» — убирает значок и закрывает программу.

**Окно микшера** открывается у значка, прижатым к панели задач с её стороны (снизу, сверху, слева,
справа), в 12 px от панели и края экрана. Внутри — все устройства вывода, устройство по умолчанию
первым; под каждым — его программы:

- значок программы (из её exe), имя (длинное обрезается с «…», полное — в подсказке);
- ползунок громкости, число процентов, кнопка «без звука» (подсказка «Без звука» / «Включить звук»);
- тонкая полоска под ползунком — уровень сигнала сейчас;
- нет программ — «Нет программ со звуком».

Ползунок: тянуть мышью или щёлкнуть в место; колесо над ним — ±2 %; с клавиатуры (Tab до него) —
стрелки ±2 %, PageUp/PageDown ±10 %. Громкость программы ставится всем её процессам на этом устройстве.

Окно закрывается повторным щелчком по значку, Esc, щелчком мимо окна, Alt+F4.
Само по себе (смена разрешения, новое устройство) окно не появляется и фокус не берёт.

Язык — как у системы (русский, иначе английский), тема — как у программ Windows (светлая или тёмная).

## Консольные ключи

Работают и при запущенном трее; только читают — громкость и устройства не меняют. Неизвестные ключи —
печатается подсказка (код выхода 0). Если ключей несколько, побеждает первый из `--version`,
`--list`, `--watch`.

### Снимок: `kamerton --list`

Печатает устройства и под каждым — его программы, затем выходит:

```
[out] Speakers (Demo Audio) 100% default
    Web Browser 100% (pid 4100,4120)
    System sounds 100% (pid 0)
[in] Microphone (Demo Audio) 50% default
```

- `[out]` / `[in]` — вывод или ввод; `default` — устройство по умолчанию; `muted` — без звука.
- Процессы одного exe на одном устройстве — одна строка, их pid через запятую.
- Имя программы: из сессии Windows, иначе описание файла («Web Browser» вместо «browser»), иначе имя
  exe, иначе `pid <n>`.

### Поток событий: `kamerton --watch [--peaks] [--for <s>]`

Печатает снимок, строку `watching, Ctrl+C to stop`, затем каждое изменение строкой со временем от
запуска:

```
    5.023s  app added      Music Player 100% (pid 5200)
    7.410s  device changed [out] Speakers (Demo Audio) 64% default
    7.500s  peaks  Music Player 0.42
```

- События: `device added/removed/changed`, `app added/removed/changed`. В `removed` — не имя, а ключ:
  id устройства или путь exe в нижнем регистре.
- `--peaks` — раз в 500 мс строка `peaks` с уровнями (0–1) программ, у которых сейчас есть звук.
- `--for <s>` — остановиться через `<s>` секунд; иначе — по Ctrl+C. Не число — ошибка
  `--for needs a number of seconds`, код выхода 2.
- В конце: `stopped, subscriptions left: 0` — сколько подписок на события Windows осталось
  неснятыми (должно быть 0).

`kamerton --help` — подсказка, `--version` — версия.
