# Kamerton — замысел и этапы

Микшер громкости в трее для Windows 10/11 — аналог EarTrumpet. Запрос владельца 22.10.2026:
«хороший аналог EarTrumpet»; имя Kamerton выбрано владельцем в тот же день.

## Чем EarTrumpet хорош и где слаб (на 22.10.2026)

- Умеет: громкость программ в выпадающем окне у трея, индикаторы уровня, перевод программы на другое
  устройство, устройство по умолчанию, горячие клавиши, колесо над значком, логарифмическая шкала,
  темы, 20+ языков. C#/WPF, версия 2.3.0.0, единственный сопровождающий без времени (issue #1838).
- Главные жалобы: утечки памяти и ЦП (#1424, #1722, #1740); окно не там и не того размера (#1304, #1704);
  крадёт фокус, мешает играм на весь экран (#453, #1588); программы пропадают из списка, сбрасывается
  громкость (#1845, #1249); после смены устройства программы не переходят (#1113).
- Просят и нет: горячие клавиши на отдельную программу, переключение устройств с клавиатуры (обсуждение #648).

## Цели

- Лёгкость: в покое < 30 МБ памяти и ≈ 0 % ЦП, без утечек за недели работы.
- Окно всегда на месте: любые мониторы, масштабы, положение панели задач; своё место по желанию.
- Не крадёт фокус, не мешает играм.
- Ничего не теряет: программы, устройства и громкость отслеживаются по событиям Windows.

## Не хуже EarTrumpet: что взять и где (разбор исходников 22.10.2026)

Полный разбор — `kamerton-scratch/reports/eartrumpet.md` (вне репозитория). Владелец 22.10.2026: «функционал
не хуже, минусы учтены».

| Этап | Функции EarTrumpet, которых ещё нет | Их минусы, которые учесть |
|---|---|---|
| 0.2 (доделка) | средний щелчок по значку — «без звука» у устройства по умолчанию; свернуть/развернуть: только устройство по умолчанию или все, запоминается; клавиши на строке (M — без звука, ±); тихий звук при отпускании ползунка устройства; Esc возвращает фокус в трей; колесо вне окна, пока оно открыто (настройка) | окно открывается медленно (#1418) — у нас окно должно появляться за кадр; анимация с выключателем; повторный щелчок по значку не открывает окно снова (дебаунс 300 мс) |
| 0.3 | устройство по умолчанию из меню значка (с галкой); перевод программы на устройство (меню строки и перетаскивание между устройствами — 40 голосов); микрофоны в окне; сразу «по умолчанию» и «связь»; подменю старых окон Windows (запись, воспроизведение, панель «Звук») | звук не переезжает на устройство (#1307, #1113); «прослушивать» путает устройства (#904, #415); Bluetooth не возвращает звук (#1209); audiodg виден как программа (#1095) |
| 0.4 | горячие клавиши: открыть окно, микшер, настройки, громче/тише всё; на отдельную программу (просят); переключить вывод (просят) | хоткей перестаёт работать (#1120) |
| 0.5 | память громкости и устройства программы; громкость по умолчанию для новых программ (просят) | громкость сбрасывается на 100 % (#1249, #1495), устройство не запоминается (#521) |
| 0.6 | полное окно микшера (запоминает место); настройки с поиском; логарифмическая шкала; старый вид значка; скрыть программы и устройства (самое просимое: 61 и 50 голосов); баланс; пространственный звук вкл/выкл; больше языков (у них 20+) | значок не в стиле Win11 (#1385), высокий контраст (#1270), нет OSD при смене громкости (#1545) |
| 0.7 | — | окно не там после сна и смены DPI (#1304), кража фокуса при смене разрешения (#453), не закрывается при открытом «Пуске» (#897), открывается и закрывается над игрой (#836), мешает играм на весь экран (#1588); утечки и ЦП (#1424, #1722, #1740, #1651); пропадают программы (#1305, #1845), после смены пользователя (#1469), замёрзший значок (#1531) |

Не берём: телеметрию (у них включена по умолчанию вне ЕС); аддон Actions — его триггеры и действия
покрывают профили 0.5. Обновления — через `anvil-update`, а не Microsoft Store.

## Риски

- Перевод программы на другое устройство — только через недокументированные API; обновление Windows
  может их сломать.
- Выпадающее окно на egui: прозрачность, анимация, место на Win10 и Win11 — проверить на первом этапе
  окна (прозрачность окна OpenGL на Windows бывает ненадёжна).
