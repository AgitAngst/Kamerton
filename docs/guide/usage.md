# Как пользоваться

## В трее: `kamerton`

Запуск без ключей ставит значок в трей; окон на экране нет. Второй запуск без ключей ничего не делает
и сразу выходит — значок остаётся один. Окно микшера готово с самого старта, только спрятано: по щелчку
оно появляется за кадр (~10 мс). В покое Kamerton занимает ~20–28 МБ своей памяти и не тратит процессор.

**Значок** показывает громкость устройства вывода по умолчанию; вид — на выбор в «Настройки → Значок → В
трее»:

- **«Знак»** (по умолчанию) — знак Kamerton, камертон-микшер: ручки зубцов стоят по громкости левого и
  правого канала (с учётом баланса, по шкале ползунков). Без звука — ручки внизу, знак бледнеет.
- **«Колонка»** — классический динамик с волнами: 0 % — без волн, до 33 % — одна, до 66 % — две, выше —
  три; без звука — крестик. Светлее на тёмной панели задач, темнее на светлой.

Цвет — «Пурпур» или «Лазурь»; тот же цвет у знака в «О программе» и у значка окна микшера. Движение: громкость меняется — ручки (волны) плавно доезжают за 200 мс;
сменилось устройство вывода по умолчанию — зубцы коротко дрожат, как ударенный камертон (у колонки —
толчок и волна наружу); при запуске ручки пробегают вниз-вверх (волны загораются по одной). Нет
устройства вывода по умолчанию (например, все отключены) — ручки (колонка) красные, пока оно не появится.
Остановка службы звука Windows обычно тоже убирает устройства, но это ещё не проверено вживую. В Windows
выключено «Показывать анимацию» — всё меняется сразу. Подсказка: `Kamerton: <устройство> — <громкость> %`.

- **Щелчок** — открыть или закрыть окно микшера.
- **Средний щелчок** — «без звука» у устройства вывода по умолчанию.
- **Колесо над значком** — громкость устройства по умолчанию: 2 % за щелчок колеса, вверх — громче.
- **Плашка громкости** (с этапа 1.0) — пока окно микшера закрыто, колесо над значком, средний щелчок и сочетания
  «Громче», «Тише», «Без звука» показывают у панели задач, по центру, плашку: значок динамика (перечёркнутый —
  «без звука»), полоска громкости и число. Висит 1,5 с после последнего изменения, не берёт фокус; щелчок по
  значку в это время открывает окно микшера. Выключатель — «Настройки → Окно → Плашка громкости» (`osd`).
  Громкость программ (сочетания на программу) плашку не показывает.
- **Правая кнопка** — меню:
  - устройства вывода, у устройства по умолчанию — отметка; выбор — сделать его устройством по
    умолчанию (и для связи);
  - «Окна Windows»: «Микшер громкости Windows» (`sndvol.exe`), «Устройства воспроизведения»,
    «Устройства записи», «Звуки» (`control mmsys.cpl,,0|1|2`), «Параметры звука» (`ms-settings:sound`);
  - «Выход» — убирает значок и закрывает программу.

**Окно микшера** открывается у значка, прижатым к панели задач с её стороны (снизу, сверху, слева,
справа), в 12 px от панели и края экрана. Вид — как «Вывод звука» в быстрых настройках Windows 11:

- **«Устройство вывода»** — список всех устройств вывода, у каждого свой ползунок, число и «без звука».
  Устройство по умолчанию подсвечено и отмечено синей чертой слева; щелчок по строке делает устройство
  основным. Значок — по имени устройства: колонка, наушники, монитор.
- **«Микшер громкости»** — программы всех устройств вывода, сначала основного; «Системные звуки» —
  один раз, у основного устройства. Программа, которая играет
  не на основном устройстве, — с мелкой подписью «→ устройство» рядом с именем.
- **Основное устройство «без звука»** — над программами жёлтая полоса «Устройство без звука» /
  «Программы на нём не слышно» с кнопкой «Включить» (снимает «без звука» с устройства); ползунки и числа
  программ этого устройства серые. У микрофона — «Микрофон без звука» / «Программы его не слышат».
- **Полоса внизу** — «Другие параметры звука» со значком «наружу» (открывает `ms-settings:sound`), справа
  «Профили», «Настройки» (шестерёнка) и, за чертой, кнопка с микрофоном и стрелкой — «Показать устройства
  ввода» / «Скрыть устройства ввода»:
  раздел «Устройство ввода» — микрофоны, под ними «Программы записи» (без «Системных звуков»; нет
  программ — «Микрофон никто не слушает»). Выбор запоминается (`%APPDATA%\Kamerton\settings.txt`,
  `expanded=0|1`).

Строки программ (`audiodg.exe` не показывается):

- значок программы (из её exe), имя (длинное обрезается с «…», полное — в подсказке); у программы, чьё
  имя узнать не удалось, — «Неизвестная программа» и мелко «PID <номер процесса>»;
- ползунок громкости, число процентов, кнопка «без звука» (подсказка «Без звука» / «Включить звук»);
- тонкая полоска под ползунком — уровень сигнала сейчас;
- нет программ — «Нет программ со звуком».

Ползунок: тянуть мышью или щёлкнуть в место; колесо над ним — ±2 %; с клавиатуры (Tab до него) —
стрелки, `+` и `-` — ±2 %, PageUp/PageDown — ±10 %, M — «без звука». Громкость программы ставится всем
её процессам на этом устройстве. Отпустили ползунок устройства — звучит короткий системный звук.

**Правый щелчок по строке устройства** — «Сделать устройством по умолчанию», «Сделать устройством связи»
(у текущих — галочка), «Без звука» / «Включить звук».

**Правый щелчок по строке программы** (и по её значку) — сверху «Устройство»: «Как в системе» (снять
закрепление) и устройства того же направления, сразу в меню; галочка — куда программа закреплена. Ниже —
«Без звука» / «Включить звук», «Горячие клавиши…», «Скрыть». Если в этой версии Windows перенос
недоступен — серый пункт «Недоступно в этой версии Windows».

**Перетаскивание**: строку программы можно взять левой кнопкой за значок или имя и отпустить над строкой
другого устройства того же направления — программа переносится туда (как «Параметры → Громкость приложений»).
Пока тянете, подходящие блоки подсвечены. Некоторые программы переходят на новое устройство только с
новым воспроизведением — так ведёт себя Windows.

**Устройство программы помнится.** Windows держит закрепление за процессом и забывает его, когда программа
закрывается. Kamerton запоминает выбор из меню и перетаскивания (`approute=` в `settings.txt`) и при следующем
появлении программы ставит её на то же устройство, если оно подключено. «Как в системе» стирает память.
Программы, уже работавшие к запуску Kamerton, не переставляются.

Окно закрывается повторным щелчком по значку, Esc, щелчком мимо окна, Alt+F4.
Само по себе (смена разрешения, новое устройство) окно не появляется и фокус не берёт.

Язык — как у системы (русский, иначе английский), тема — как у программ Windows (светлая или тёмная).

## Настройки

Шестерёнка внизу окна, рядом с «Профили», — страница «Настройки» (стрелка «Назад» — обратно):

- Наверху — поле «Поиск по настройкам», под ним переходы «Горячие клавиши», «Профили» и «Правила» (строки со
  стрелкой справа). Пока в поле есть текст, остаются только подходящие строки и разделы (подпись или ключевые слова, по-русски
  и по-английски, регистр не важен, несколько слов — все сразу); ничего нет — «Ничего не найдено». Esc очищает
  запрос, а не закрывает окно; запрос сбрасывается при закрытии окна и по «Назад».
- «Оформление»: тема — «Система» / «Светлая» / «Тёмная», язык — «Система» / «Русский» / «English»;
  меняются сразу.
- «Значок»: «В трее» — «Знак» / «Колонка», «Цвет» — «Пурпур» / «Лазурь» (ключи `tray_icon`, `tray_color`); в сегментах — образец: у «Знак» и «Колонка» маленький значок трея в выбранном цвете, у цвета — точка.
  Цвет — у значка в трее, у знака в «О программе» и у значка окна микшера (заголовок, панель задач; открытое
  окно микшера перекрашивается, когда получает фокус). Значок самого exe в Проводнике и у ярлыков вшит при
  сборке и остаётся пурпурным. Значок в трее меняется сразу.
- «Окно»: «Анимация открытия» — окно въезжает на 12 px от панели задач за 180 мс (если в Windows
  выключено «Показывать анимацию» — сразу); «Окно микшера поверх всех окон» (`mixer_on_top`) — окно «Микшер Kamerton»
  не прячется за другими окнами, вступает в силу при следующем открытии окна микшера; «Колесо вне окна меняет громкость» — пока окно открыто,
  колесо где угодно вне окна меняет громкость устройства по умолчанию на 2 %; «Логарифмическая шкала» —
  громкость = положение² (середина ползунка — 25 %), число рядом — громкость; «Плашка громкости» — см. выше.
- «Система»: «Запускать при входе в Windows» — значение `Kamerton` в
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`; «Проверять обновления» и «Предлагать пред-выпуски».
- «Скрытое»: что скрыто через «Скрыть» в меню строки программы или устройства; «Показать» — вернуть.
  Скрытое не видно в окне, в окне микшера и в меню значка.
- Шапка страницы (с 1.3.4; раньше — раздел «О программе» внизу): сверху знак Kamerton, «Kamerton» и «Версия X.Y.Z» — при
  каждом открытии «Настроек» у знака пробегают ручки, как моторизованные фейдеры пульта; ниже, отдельной полосой — проверка обновления:
  строка состояния («Последняя версия», «Проверка…», «Доступна X.Y.Z», «Загрузка X.Y.Z · N %», «Скачана X.Y.Z»,
  «Не удалось проверить» и под ней текст ошибки) и кнопка по состоянию — «Проверить сейчас», «Пропустить» и
  «Обновить», «Перезапустить», «Повторить». У переносной копии под шапкой — «Переносная копия: настройки рядом с exe».

## Окно микшера

Меню значка → «Микшер Kamerton» (или сочетание «Открыть микшер») — обычное окно: колонки устройств
под подписями «Вывод» и «Ввод». В колонке — строка устройства (значок; у основного — синяя черта у края и
метка «Основное»), «Баланс» (у стереоустройств: «Л» — середина — «П», справа значение «Центр» / «Л 20» /
«П 35», полоска идёт от середины к ручке; в сторону — противоположный канал тише; возле середины ползунок
встаёт ровно в середину; громкость устройства баланс не меняет) и программы
со всеми действиями выпадающего окна (меню строк, перетаскивание между колонками). Размер окна подстраивается
сам: ширина — по числу устройств (колонок), высота — по самой длинной колонке; больше экрана окно не
растёт, дальше — прокрутка. Окно запоминает место (`mixer_rect` в `settings.txt`); второй запуск выводит
открытое окно наверх.

## Горячие клавиши

Шестерёнка внизу окна → страница «Настройки» → «Горячие клавиши» (стрелка «Назад» — обратно).
Одна страница: слева действие, справа поле сочетания в рамке. По умолчанию сочетаний нет. Сочетания
устройств стоят под подписью «Сделать основным:».

| Раздел | Действие | Что делает |
|---|---|---|
| Окно | «Открыть окно» | открыть или закрыть окно у значка |
| Окно | «Открыть микшер» | окно микшера Kamerton |
| Громкость | «Громче», «Тише» | громкость устройства вывода по умолчанию ±2 % |
| Громкость | «Без звука» | «без звука» у устройства по умолчанию |
| Устройство вывода | «Следующее», «Предыдущее» | сделать по умолчанию следующее / предыдущее устройство вывода, по кругу |
| Устройство вывода | имя устройства | сделать это устройство основным |
| Устройство вывода | «Громкость устройства · имя»: «Громче», «Тише», «Без звука» | громкость именно этого устройства ±2 % — основное оно или нет; показывается плашка громкости с именем устройства над полосой |
| Устройство ввода | имя устройства | сделать этот микрофон основным |

Сочетания на программу — «Громче», «Тише» (±2 %) и «Без звука» для всех её сессий на всех устройствах
вывода. Раздел программы открывается из меню её строки: «Горячие клавиши…»; программы, у которых уже
есть сочетания, видны на странице всегда.

Щелчок по полю — нажать новое сочетание: нужен Ctrl или Alt (клавиши F1–F24 — можно без них); Esc —
отмена, Backspace — убрать сочетание. Действует сразу. Красная точка у сочетания — занято другой
программой (Windows не дала зарегистрировать — сочетание держит кто-то ещё); пояснение «Занято другой
программой» внизу страницы — только когда такое сочетание есть. Там же подсказка: «Сочетания программы —
правый щелчок по её строке → «Горячие клавиши…»». В `settings.txt`:
`hotkey.<open|louder|quieter|mute|next_output|prev_output|mixer>=Ctrl+Alt+Up`,
`devhotkey.<id устройства>=Ctrl+Alt+1`,
`devvolkey.<louder|quieter|mute>.<id устройства>=Shift+VolumeUp`,
`apphotkey.<louder|quieter|mute>.<путь exe в нижнем регистре>=Ctrl+Shift+F9`.

**Медиа-клавиши громкости.** На клавиатуре нажмите `VolumeUp`, `VolumeDown` или `VolumeMute` вместе с Shift,
Ctrl или Alt, пока поле ждёт сочетание: получится, например, `Shift+VolumeUp` для второго устройства. Без
модификатора медиа-клавиши остаются у Windows и меняют основное устройство. Пока поле ждёт, Windows
отрабатывает и саму медиа-клавишу — основное устройство может один раз измениться.

## Профили и память громкости

Кнопка со стопкой листов внизу окна — страница «Профили».

- «Запоминать громкость программ» (включено по умолчанию): громкость и «без звука» каждой программы на
  устройствах вывода запоминаются по пути exe; программа появилась снова с другой громкостью — Kamerton
  возвращает запомненную.
- «Громкость новых программ»: программа, которой ещё нет в памяти, при первом появлении получает эту
  громкость (ползунок под выключателем).
- Профиль — устройство вывода и записи по умолчанию и для каждой программы громкость, «без звука» и
  устройство. «Сохранить текущее» — новый профиль из того, что есть сейчас (имя можно изменить в поле).
  «Применить» — устройства профиля становятся устройствами по умолчанию (если подключены), запущенным
  программам — громкость, «без звука» и устройство из профиля, незапущенным — громкость в память.
  Корзина — удалить (с подтверждением).
- «Включать при подключении» — устройство, при подключении которого профиль применяется сам (при
  запуске Kamerton правило не срабатывает).
- Меню значка → «Профили» — применить любой профиль.

В `settings.txt`: `remember=1`, `newapp_volume=50`, `appvol=<exe>|<проценты>|<0|1>`,
`profile.<N>.name|output|input|on_connect=…`, `profile.<N>.app=<exe>|<проценты>|<0|1>|<устройство или ->`.

## Правила

«Настройки» → «Правила» (стрелка «Назад» — обратно). Три раздела; всё сохраняется сразу (`settings.txt`) и вступает в
силу сразу.

- **«Потолок громкости»** (с этапа 1.1). Выключатель «Общий (устройство по умолчанию)» и ползунок 1–99 %: громкость
  устройства вывода по умолчанию не поднимется выше. Ниже — потолки программ (строка: имя, корзина, ползунок); «Добавить
  программу…» — из запущенных сейчас. Что-то (программа, колесо, сочетание, сама Windows) подняло громкость выше потолка —
  Kamerton возвращает её на потолок (по снимку после каждого изменения и при запуске). Громкость ниже потолка не
  трогается. Ключи: `limit_device=NN`, `limit_app.<exe>=NN`.
  **«Ночью тише»** (с этапа 1.2) — выключатель под общим потолком: «С» и «До» (местное время, шаг 30 минут; «С» позже
  «До» — через полночь, например 23:00–07:00; равные — никогда; «До» не входит) и «Потолок ночью» 1–99 % (по умолчанию
  40). В эти часы общий потолок — меньший из дневного (если задан) и ночного; утром ночной потолок перестаёт действовать, но
  громкость сама не растёт. Граница часов замечается за минуту. Ключи: `night=1`, `night_from=HH:MM`, `night_to=HH:MM`,
  `night_limit=NN`.
- **«Приглушение»**. Выключатель «Приглушать остальные программы», ползунок «Приглушать до (от прежней громкости)» —
  5–95 %, по умолчанию 30, и список «Главные программы» (корзина, «Добавить программу…»). Пока хоть одна главная программа
  звучит (пик выше 0,02, как полоска уровня), остальные программы вывода — кроме «Системных звуков» и программ «без
  звука» — тише: прежняя громкость × доля. Главные молчат 1,5 с — громкость возвращается. Громкость, которую вы поменяли
  сами во время приглушения, не трогается и не возвращается. Приглушённая громкость не попадает в «память громкости».
  Выключили приглушение или вышли из Kamerton — всё возвращается. Пока Kamerton закрыт аварийно, приглушённое остаётся
  приглушённым (поправить ползунком). Проверяет звук 4 раза в секунду, только пока приглушение включено и главные
  выбраны. Ключи: `duck=1`, `duck_level=NN`, `duck_app=<exe>`.
- **«Правила по программам»**. Карточка: программа (из запущенных), «Когда» — «Программа запущена» или «Подключено
  устройство: …», «Устройство» — «Не менять» / «Как в системе» / устройство вывода, «Задать громкость» с ползунком,
  «Выключить звук»; корзина с подтверждением в той же строке; «Добавить правило». Правило срабатывает один раз, когда
  программа появляется (условие верно в этот момент) или подключается устройство из условия (программа уже играет);
  дальше вы вольны менять сами. Правила идут после памяти громкости и профилей — что задано правилом, побеждает.
  Программа без выбранного в карточке exe (правило только что добавлено) в `settings.txt` не сохраняется. Ключи:
  `rule.<N>.app|when|device|volume|muted` (`when=running|device:<id>`, `device=keep|system|<id>`).

## Консольные ключи

Работают и при запущенном трее. `--list`, `--watch` и `--get` только читают; `--set` и `--mute` меняют
громкость и «без звука» цели, но не устройства и не маршруты. Неизвестные ключи — печатается подсказка (код
выхода 0). Команды управления (`--set`, `--mute`, `--get`) главнее `--version`, `--list`, `--watch`; из
нескольких команд управления выполняется та, что стоит раньше. Весь вывод — по-английски.

### Снимок: `kamerton --list`

Печатает устройства и под каждым — его программы, затем выходит:

```
[out] Speakers (Demo Audio) 100% default
    Web Browser 100% (pid 4100,4120)
    System sounds 100% (pid 0)
[in] Microphone (Demo Audio) 50% default
```

- `[out]` / `[in]` — вывод или ввод; `default` — устройство по умолчанию; `muted` — без звука.
- Процессы одного exe на одном устройстве — одна строка, их pid через запятую.
- Имя программы: из сессии Windows, иначе описание файла («Web Browser» вместо «browser»), иначе имя
  exe (у процесса, который не открыть, — из идентификатора сессии), иначе `?`.

### Поток событий: `kamerton --watch [--peaks] [--for <s>]`

Печатает снимок, строку `watching, Ctrl+C to stop`, затем каждое изменение строкой со временем от
запуска:

```
    5.023s  app added      Music Player 100% (pid 5200)
    7.410s  device changed [out] Speakers (Demo Audio) 64% default
    7.500s  peaks  Music Player 0.42
```

- События: `device added/removed/changed`, `app added/removed/changed`. В `removed` — не имя, а ключ:
  id устройства или путь exe в нижнем регистре.
- `--peaks` — раз в 500 мс строка `peaks` с уровнями (0–1) программ, у которых сейчас есть звук.
- `--for <s>` — остановиться через `<s>` секунд; иначе — по Ctrl+C. Не число — ошибка
  `--for needs a number of seconds`, код выхода 2.
- В конце: `stopped, subscriptions left: 0` — сколько подписок на события Windows осталось
  неснятыми (должно быть 0).

### Управление: `kamerton --set`, `--mute`, `--get` (этап 1.0)

```
kamerton --set <цель> <громкость>
kamerton --mute <цель> [on|off|toggle]
kamerton --get <цель>
```

Отдельный процесс на время команды (трей не нужен); трей и окно узнают об изменении от Windows.

- **Цель:** `default` — устройство вывода по умолчанию, `input` — устройство ввода по умолчанию; иначе имя
  программы (как в окне или имя exe без `.exe`), затем имя устройства. Регистр не важен; точное совпадение
  важнее части имени. Программа — по всем её сессиям на всех устройствах вывода. Подошли несколько разных
  программ или устройств — ничего не меняется, в stderr их список.
- **Громкость:** `45`, `45%` (0–100) или `+5`, `-5` (от текущей; у программы — от своей на каждом устройстве,
  результат обрезается до 0–100).
- **`--mute`:** `on`, `off`, `toggle` (по умолчанию). `toggle` у программы: хоть одна сессия звучит —
  заглушить все, иначе включить все.
- **Вывод:** `Speakers (Demo Audio): volume 54%, not muted` (`--get`), `…: volume 30%` (`--set`),
  `…: muted` / `…: not muted` (`--mute`).
- **Коды выхода:** 0 — готово; 1 — ошибка звука Windows; 2 — неверные ключи или громкость; 3 — цель не
  найдена или неоднозначна.

`kamerton --help` — подсказка, `--version` — версия.

## Обновления

Kamerton сам проверяет выпуски на GitHub: при запуске (через минуту) и раз в сутки. Нашлась новая версия —
в шапке «Настроек» появляется «Обновить», а в меню значка — «Обновить до X.Y.Z». Архив скачивается в фоне и
сверяется по `SHA256SUMS`; потом — «Перезапустить на X.Y.Z». Что бы ни сломалось, остаётся старая версия.
«Пропустить» — эта версия больше не предлагается сама (кнопка «Проверить сейчас» покажет её всё равно).
Выключатели: «Проверять обновления» (`updates=0|1` в `settings.txt`), «Предлагать пред-выпуски»
(`prerelease`); пропущенная версия — `skip_version`.

**Лимит запросов GitHub.** Проверка спрашивает у GitHub список выпусков без токена, а таких запросов — 60 в час на адрес
(их выбирают соседи по сети, VPN, другие программы). Ответ 403 или 429 с версии 1.3.6 не тупик: Kamerton сам узнаёт
последний обычный выпуск через страницу выпусков (без заметок к выпуску; пред-выпуски так не видны) и предлагает
«Обновить» как обычно. Не вышло и это — в шапке «Настроек» «Не удалось проверить» и понятный текст: «Лимит запросов GitHub
(HTTP 403): повторите примерно через N мин»; кнопка «Повторить».

## Переносная копия

Архив выпуска `kamerton-X.Y.Z-windows-x64.zip` — один `kamerton.exe`, установки нет. Обычно настройки
лежат в `%APPDATA%\Kamerton\settings.txt`. Положите рядом с exe пустой `settings.txt` — копия станет
переносной: настройки и журнал падений `crash.log` будут в её папке, а в шапке «Настроек»
появится пометка «Переносная копия».
