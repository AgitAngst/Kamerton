## Решения

- Kamerton самостоятельный: код других проектов владельца не читается и не копируется.
- Рисует OpenGL (`Renderer::Glow`): с wgpu (по умолчанию в eframe, его тянет anvil-ui) процесс держал
  ~560 МБ. С glow в покое — ~80 МБ своей памяти: это контекст OpenGL видеодрайвера; цель SPEC < 30 МБ
  не достигнута — см. «Ждёт владельца».
- eframe сам показывает окно после первого кадра: окно создаётся за экраном и прячется на втором кадре,
  если его не открывали (иначе висело и перерисовывалось 30 раз в секунду).
- Показ/прятание окна — Win32 из потока трея (спрятанное окно eframe не рисует); фокус — только при
  показе по щелчку.
- Список сессий Windows не перебирается повторно (утечка ~26 КБ на процесс, починена в 0.1).
- Тесты утечки грузят ПК — гонять только с согласия владельца. Не убивать Kamerton `taskkill` — значок
  остаётся «призраком»; закрывать `scripts/quit.ps1`.

## Ждёт владельца

- Живая проверка трея и окна (список выше «Не проверено»).
- Память в покое ~80 МБ при цели < 30 МБ. Варианты: оставить; окно в отдельном процессе, который
  запускается по щелчку (в покое — только трей, несколько МБ, окно открывается дольше); свой программный
  рисовальщик egui без видеодрайвера.
- Пуш этапа 0.2 на GitHub (коммиты локальные).
- Репозиторий `AgitAngst/Kamerton` публичный: в документы и снимки — только выдуманные данные.
