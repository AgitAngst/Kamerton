## Что это и что уже работает

Микшер громкости в трее для Windows 10/11. Сейчас есть ядро звука (этап 0.1):

- устройства вывода и ввода, устройство по умолчанию, их громкость и «без звука»;
- программы со звуком на каждом устройстве — процессы одного exe слиты в одну программу;
- изменения приходят по событиям Windows, без опроса; уровни сигнала — по запросу;
- консольные режимы `--list` и `--watch` — только чтение.

Не сделано: трей и окно (0.2), смена устройства по умолчанию и перевод программ (0.3) и всё дальше по
[SPEC.md](../SPEC.md).
