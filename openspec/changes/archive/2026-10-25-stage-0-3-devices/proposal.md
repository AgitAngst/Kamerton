## Why

Этап 0.3 по SPEC.md — «Устройства»: без смены устройства по умолчанию и переноса программ на другое
устройство Kamerton уступает EarTrumpet в главном. Заодно — доделки 0.2 из таблицы паритета в SPEC.md
(средний щелчок, свернуть/развернуть, клавиши на строке).

## What Changes

- Устройство по умолчанию: сделать устройство устройством по умолчанию (все роли) или только устройством
  связи — из меню значка и из меню строки устройства в окне. В снимке — признак «для связи».
- Перенос программы на устройство (как «Параметры → Громкость приложений»): из меню строки программы и
  перетаскиванием строки на блок другого устройства; «Как в системе» снимает закрепление. В снимке —
  закреплённое устройство программы.
- Микрофоны: в развёрнутом окне — устройства записи и их программы (без «Системных звуков»).
- Свернуть/развернуть окно: свёрнуто — только устройство вывода по умолчанию, развёрнуто — все устройства
  вывода и записи; выбор запоминается в `%APPDATA%\Kamerton\settings.txt`.
- Меню значка: устройства вывода с отметкой текущего (щелчок — сделать по умолчанию), подменю старых окон
  Windows (воспроизведение, запись, «Звук»).
- Средний щелчок по значку — «без звука» у устройства по умолчанию. Клавиши на строке: M — без звука,
  `+`/`-` — громкость.
- `audiodg.exe` не показывается как программа (EarTrumpet #1095).
- Недокументированные API (`IPolicyConfig`, `AudioPolicyConfig`) — только в `src/audio/policy.rs`; сбой
  отключает свою функцию (пункты меню недоступны с пояснением), а не программу.
- Версия 0.3.0.

## Capabilities

### New Capabilities

- `device-control`: устройство по умолчанию и устройство связи — чтение и смена.
- `app-routing`: закреплённое устройство программы — чтение, перенос, сброс.
- `flyout-actions`: меню строк, перетаскивание, микрофоны, свернуть/развернуть, клавиши на строке.
- `tray-menu`: устройства в меню значка, старые окна Windows, средний щелчок.
