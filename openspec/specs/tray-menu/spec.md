# tray-menu Specification

## Purpose
Меню значка как пульт устройств: выбор устройства вывода по умолчанию, ссылки на старые окна Windows и
«без звука» средним щелчком.

## Requirements

### Requirement: Устройства в меню значка
Меню значка SHALL начинаться со списка устройств вывода, у устройства по умолчанию — отметка; выбор
пункта SHALL делать устройство устройством по умолчанию. Нет устройств — строка «Нет устройств вывода
звука», недоступная.

#### Scenario: Выбор колонок
- **WHEN** в меню значка выбирают «Колонки»
- **THEN** колонки становятся устройством по умолчанию, значок и подсказка обновляются

### Requirement: Старые окна Windows
Меню значка SHALL иметь подменю «Окна Windows» («Windows panels») с пунктами «Устройства
воспроизведения», «Устройства записи», «Звуки», «Микшер громкости Windows», «Параметры звука».

#### Scenario: Устройства записи
- **WHEN** выбирают «Окна Windows → Устройства записи»
- **THEN** открывается панель «Звук» на вкладке «Запись»

### Requirement: Средний щелчок
Средний щелчок по значку SHALL переключать «без звука» у устройства вывода по умолчанию.

#### Scenario: Тишина средним щелчком
- **WHEN** по значку щёлкают средней кнопкой
- **THEN** у устройства по умолчанию включается «без звука», значок перечёркнут
