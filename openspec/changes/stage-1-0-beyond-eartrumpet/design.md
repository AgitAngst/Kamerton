# Design

## Решения

1. **Командная строка — свой процесс.** `--set/--mute/--get` запускают `Audio::start` (как `--list`), делают
   одну команду через `Control` и выходят. Трей не нужен и не трогается; изменение к нему приходит событием
   Windows. Консольный вывод — по-английски. Коды выхода: 0 — готово, 1 — ошибка звука, 2 — неверная команда,
   3 — цель не найдена или неоднозначна.
2. **Цель.** `default` — устройство вывода по умолчанию, `input` — устройство ввода по умолчанию; иначе имя
   программы (имя в окне или имя exe без `.exe`), затем имя устройства. Точное совпадение важнее части имени,
   регистр не важен; несколько разных программ или устройств — ошибка со списком. Программа — по всем её
   сессиям на всех устройствах вывода (как у сочетаний клавиш). Громкость: `45`, `45%`, `+5`, `-5` (проценты).
3. **Плашка — то же окно egui.** Второго окна нет: окно микшера (скрытое под плащом) в режиме плашки меняет
   размер на 260 × 56, встаёт у панели задач по центру, показывается без фокуса и прячется через 1,5 с. Так
   плашка получает шрифты, тему и язык набора; память — те же ~25 МБ. Плашку не показывать, если окно микшера
   открыто пользователем. Окно плашки не берёт фокус (`WS_EX_NOACTIVATE`); сквозного клика нет — слоистое окно с цепочкой кадров D3D
   надёжно не показывается. Щелчок по значку, пока плашка висит, открывает окно микшера.
4. **Высокий контраст.** `SystemParametersInfoW(SPI_GETHIGHCONTRAST)`; флаг `HCF_HIGHCONTRASTON` включает
   палитру из `GetSysColor` (`COLOR_WINDOW`, `COLOR_WINDOWTEXT`, `COLOR_GRAYTEXT`, `COLOR_HIGHLIGHT`,
   `COLOR_HIGHLIGHTTEXT`, `COLOR_BTNFACE`). Своих hex нет: цвета берутся из системы и кладутся в `Visuals` egui.
5. **Усиление выше 100 % — не в этом этапе.** `ISimpleAudioVolume` и `IAudioEndpointVolume` ограничены 1,0
   (0 дБ). Выше можно только своей обработкой звука: захват звука программы (process loopback, Windows 10 2004+)
   и повторный вывод с усилением при громкости оригинала 0 — задержка 20–40 мс, хрупко с играми и защитой
   контента, по сути свой маршрутизатор. Второй путь — свойства драйвера («Выравнивание громкости»), у разных
   драйверов разные, как пространственный звук (отложен). Решение владельца нужно.
6. **Поиск по настройкам.** Строки страницы — список `(раздел, подпись, ключевые слова)`; фильтр без учёта
   регистра по подписи и ключевым словам в обоих языках; раздел без подходящих строк скрывается. Чистая
   функция с тестами.
