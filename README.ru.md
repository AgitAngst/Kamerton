## Чем лучше EarTrumpet

EarTrumpet хорошо делает одно: громкость программ во всплывающем окне у трея. Kamerton делает это тоже — и идёт дальше.

- 🎚️ **Любое устройство, а не только основное.** У каждого устройства вывода свой ползунок, и на каждое можно
  повесить свои сочетания — громче, тише, без звука, — основное оно или нет. Убавить наушники, не трогая колонки;
  `Shift+VolumeUp` — на второе устройство, и медиа-клавиши управляют обоими.
- 🧠 **Помнит.** Громкость и «без звука» программы возвращаются, когда она запускается снова; новые программы
  стартуют с заданной громкостью; устройство, куда вы перенесли программу, помнится и после её закрытия (Windows
  забывает).
- 🗂️ **Профили.** Устройства по умолчанию + громкость, «без звука» и устройство каждой программы — одним профилем;
  применить из меню трея или само при подключении устройства.
- 🛡️ **Правила.** Потолок громкости (общий и по программам), выше которого ничто не поднимет; **«Ночью тише»** по
  часам; **автоприглушение** (заговорил созвон — остальное тише, потом возвращается); правила по программам
  («запустился Discord — на гарнитуру, 60 %»).
- ⌨️ **Сочетания на всё.** Общая громкость, следующее/предыдущее устройство, по устройству, по программе. Занятые
  другой программой сочетания отмечены.
- 💻 **Командная строка.** `kamerton --set spotify 30`, `--mute default toggle`, `--get input` — для скриптов, с
  кодами выхода. Плюс `--list` и живой поток событий `--watch`.
- 📊 **Плашка громкости** у панели задач при колесе над значком и сочетаниях — с именем устройства, которое
  изменилось.
- ⚖️ **Баланс** (Л/П) устройства в окне микшера.
- 🎙️ **Микрофоны** и программы записи — в том же окне, одной кнопкой.
- 🪶 **Маленький и родной.** Один exe на Rust и Direct3D 11. Без установщика, среды выполнения и Store. Положите
  рядом пустой `settings.txt` — копия станет переносной.
- 🔄 **Обновляется сам** с GitHub Releases со сверкой SHA-256; что-то пошло не так — остаётся старая версия.

## Возможности

**Трей**
- Значок показывает громкость основного устройства (знак-камертон или классическая колонка, пурпур или лазурь).
- Щелчок — окно · средний щелчок — без звука · колесо — ±2 % · правая кнопка — устройства, профили, окна звука Windows.

**Окно у трея** (вид быстрых настроек Windows 11, прижимается к панели задач с любой стороны)
- Все устройства вывода с ползунками, «без звука» и уровнем сигнала; щелчок — сделать основным.
- Все программы всех устройств; у играющей не на основном — подпись с устройством.
- Перетащите программу на другое устройство; правый щелчок — устройство, без звука, сочетания, скрыть.
- Микрофоны и программы записи — за одной кнопкой.

**Окно микшера** — колонка на устройство, баланс, размер по содержимому, помнит место, по желанию поверх всех окон.

**Настройки** — тема, язык, автозапуск, анимация открытия, колесо вне окна, логарифмическая шкала, плашка,
скрытые программы и устройства.

**Надёжность** — пересоздаётся после перезапуска службы звука и возврата в сеанс, встаёт на место после смены
масштаба, пишет `crash.log` при падении.

## Установка

1. Скачайте `kamerton-X.Y.Z-windows-x64.zip` из [Releases](https://github.com/AgitAngst/Kamerton/releases/latest)
   (при желании сверьте с `SHA256SUMS`).
2. Распакуйте и запустите `kamerton.exe`. Автозапуск — «Настройки → Система».

Настройки — в `%APPDATA%\Kamerton\settings.txt` или рядом с exe у переносной копии.

## Командная строка

```text
kamerton --set <цель> <громкость>        # 45, 45%, +5, -5
kamerton --mute <цель> [on|off|toggle]
kamerton --get <цель>
kamerton --list | --watch [--peaks]
```

`<цель>` — `default`, `input`, имя программы (`spotify`) или устройства. Коды выхода: `0` готово, `1` ошибка
звука, `2` неверные ключи, `3` цель не найдена или неоднозначна.
