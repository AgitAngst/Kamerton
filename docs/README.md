## Что это и что уже работает

Микшер громкости в трее для Windows 10/11 (этапы 0.1 и 0.2):

- значок в трее с уровнем громкости устройства по умолчанию; щелчок — окно микшера, колесо над
  значком — громкость, правая кнопка — меню;
- окно микшера у панели задач: устройства вывода и их программы — значок, имя, ползунок, «без звука»,
  уровень сигнала; русский и английский, светлая и тёмная тема;
- ядро звука: устройства и программы, изменения по событиям Windows без опроса, уровни — только пока
  окно открыто;
- консольные режимы `--list` и `--watch` — только чтение.

- устройства (этап 0.3): устройство по умолчанию и связи — из меню значка и строки устройства; перенос
  программы на устройство — меню строки и перетаскивание; микрофоны в развёрнутом окне; средний щелчок
  по значку — «без звука».

Не сделано: горячие клавиши (0.4) и всё дальше по [SPEC.md](../SPEC.md).
