## Purpose

Быстро найти нужную строку на странице «Настройки».

## ADDED Requirements

### Requirement: Поле поиска
Страница «Настройки» SHALL содержать поле поиска под переходами на другие страницы. Пока в поле есть текст,
страница MUST показывать только строки, чья подпись или ключевые слова (в языке интерфейса и в другом языке)
содержат введённое без учёта регистра, и только разделы, где такие строки есть. Ничего не нашлось — MUST
показываться «Ничего не найдено». Поле пустое — страница как обычно.

#### Scenario: Найти автозапуск
- **WHEN** пользователь вводит «авто» (или «startup»)
- **THEN** остаётся строка автозапуска в разделе «Система»; остальные разделы скрыты
